- **2026-10-10: Wine artifacts can make idle VS Code exhaust RAM.** Observed in the adopted `technician` project, not established as an AI Kit core defect. Generated `.ai-local/` verification trees contain Wine `dosdevices/z: -> /` links (including `.ai-local/windows-build/wine/` and nested refresh-verification/artifact copies). VS Code 1.141.0 built-in npm task discovery calls `workspace.findFiles("**/package.json", "**/{node_modules,.vscode-test}/**")`; its ripgrep search uses `--hidden --no-ignore --follow`, escapes through these links into `/proc`, and emits endless loop/permission errors. The extension-host search implementation buffers stderr chunks in an array until the search ends. Observed ripgrep output exceeded 1.3 GB; Node external memory grew from 874.6 MB to 966.9 MB in 30 seconds while idle. Kernel logs from 19:08 local time show that workspace's extension host killed at 9,601,392 KiB anonymous RSS (~9.2 GiB); a later monitored run was also stopped by systemd-oomd. Workaround applied locally: user setting `search.followSymlinks: false`. Repeating the captured search without `--follow` completed in 0.032 seconds, exit 0, zero stderr bytes.
